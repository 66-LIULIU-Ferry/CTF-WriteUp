## MD5 Hash
MD5 is a cryptographic hash function algorithm that takes the message as input of any length and changes it into a fixed-length message of 16 bytes. It is useful for encoding passwords, credit cards numbers and other sensitive date into MySQL, Postgress or other databases.

For more detials, please check:
- [MD5 Algorithms](https://www.geeksforgeeks.org/what-is-the-md5-algorithm/)
